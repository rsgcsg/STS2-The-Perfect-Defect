# Data workspace

Tracked content in this directory is limited to documentation, small synthetic fixtures, and
versioned manifests. Raw/external/normalized/features/cache subdirectories are ignored.

Expected tracked paths:

```text
data/manifests/     dataset, split, provenance and license manifests
\data/gold/          redistributable annotation manifests and schemas
```

Never commit raw Headless traces, saves, proprietary game content, private identifiers, or
external data without explicit redistribution rights. See `docs/DATA_AND_PROVENANCE.md`.
